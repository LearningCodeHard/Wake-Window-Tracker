3. Daily planning

Keep awake: enter start/end and an optional label. Include travel in the interval. Tap an appointment to edit/remove it. An awake period is separate from actual wake events.

Planned nap: tap its time and pin start, duration, or both. Unpinned values remain automatic. Release a pin from its editor or Day adjustments.

No fit: the app pauses when constraints conflict, or shows a nearest legal bedtime with explicit deviation. It preserves your settings and suggests which inputs to review.

Actual sleep wins: imported real sleep overrides projections. Starting the real next nap retires its pin. A passed pin without a real log asks you to log, move or release it. If earlier records change, affected pins need review.

Clear adjustments: removes this day’s awake periods and pins together after confirmation. Actual sleep, morning wake, chosen bedtime and shared defaults remain. Release individual pins if appointments should stay.
